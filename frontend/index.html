ABOUT VOICESHIELD

Built for trustworthy voice verification.

This interface connects to the existing FastAPI /predict endpoint. The backend accepts WAV, FLAC, OGG and MP3 and runs the project's AASIST detector.

Important: if the API is offline, the interface uses an explicitly labelled demo fallback; it is not presented as a real model prediction.
